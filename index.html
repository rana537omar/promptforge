What it doesFeatures

✦Prompt to app

  • React and Tailwind web apps from plain-language requests
  • Files written one by one while you watch
  • Enhance prompt and six ready-made templates
  • Project instructions for brand, tone and rules

▶Live preview & code

  • The app runs live in the browser as it's built
  • Phone view to check mobile layouts
  • Built-in code editor with a file tree
  • Build mode for changes, Chat mode for questions

⟲Self-repairing engine

  • Missing packages installed automatically
  • Made-up or missing icons fixed
  • Components the AI forgot are written for you
  • Fix with AI: usually instant, often without the AI at all

⧉History, sharing & export

  • Undo, or restore any earlier version
  • Publish a full-screen public link in one click
  • Download a standard React project
  • Duplicate and search projects

◉A platform for many users

  • Sign-up and login with private projects per account
  • A daily build allowance per account
  • One small server with a built-in database
  • No external database to run or pay for

⛨Private by design

  • An open-source AI model on your own hardware or GPU server
  • Users' ideas and code never go to an outside AI company
  • No per-use AI fees
  • Your brand, your platform
